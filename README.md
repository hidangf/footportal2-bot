# ФУТПОРТАЛ 2

Самостоятельный Telegram-канал с нарочито некомпетентными, вымышленными спортивными новостями. Работает каждые 3 часа на GitHub Actions; ваш компьютер может быть выключен.

## Что нужно один раз сделать

1. В Telegram откройте [@BotFather](https://t.me/BotFather), выполните `/newbot`, придумайте имя и уникальный `username`. BotFather пришлёт **секретный токен**. Не отправляйте его в чаты и не публикуйте.
2. Откройте свой канал **@footportal2** → Управление каналом → Администраторы → Добавить администратора. Добавьте нового бота. Ему достаточно права **публиковать сообщения**.
3. Создайте аккаунт GitHub (если его нет) и **новый приватный репозиторий** `footportal2-bot` на [github.com/new](https://github.com/new).
4. Загрузите **все файлы из этого архива**, сохраняя структуру каталогов, включая папку `.github/workflows`. Удобно: `Add file → Upload files`; загрузка ZIP как одного файла НЕ подходит. Для Windows можно распаковать архив и загрузить его содержимое.
5. В GitHub откройте репозиторий: **Settings → Secrets and variables → Actions → New repository secret**. Создайте два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен, выданный BotFather.
   - `OPENAI_API_KEY` — ключ из [OpenAI API Keys](https://platform.openai.com/api-keys).
6. Убедитесь, что в [OpenAI API Billing](https://platform.openai.com/settings/organization/billing/overview) включена оплата API; подписка ChatGPT не оплачивает эти запросы автоматически.
7. Откройте вкладку **Actions** репозитория → выберите workflow **«ФУТПОРТАЛ 2 — публикация»** → **Run workflow**. По журналу запуска проверьте, что сообщение появилось в канале. При необходимости нажмите `Enable workflows`.

### Дальше всё самостоятельно

Запуск происходит по расписанию **каждые 3 часа**, на 17-й минуте относительно московских часов. GitHub Actions иногда откладывает запуски или даже пропускает их при перегрузке; это не гарантия запуска в точную минуту. Если нет доступных новых RSS-новостей, публикация пропускается.

В среднем система делает около 16 постов в сутки (колеблется от 8 до 24) при наличии новостей: от одного до трёх постов за запуск. Чтобы делать меньше — измените веса в `footportal.py`.

### Стоимость

GitHub Actions в приватных репозиториях предоставляется с бесплатной месячной квотой, которая для GitHub Free обычно составляет **2 000 минут/месяц**. Этого должно хватить для 8 коротких запусков в сутки при обычной работе. OpenAI API оплачивается отдельно по фактическому количеству токенов. По умолчанию выбрана относительно дешёвая модель `gpt-6-luna`. Рекомендуется установить небольшой месячный бюджет/оповещения в OpenAI.

### Как изменить стиль

Главный промпт — константа `STYLE` внутри `footportal.py`. Вероятности форматов — `FORMATS`, число публикаций за раз — в функции `run()`.

### Безопасность и прозрачность

Укажите в **описании канала**: «Юмористический проект. Все публикации — вымышленные новости, созданные нейросетью. Ссылки ведут на реальные материалы и не подтверждают содержание постов». Токены храните **только в GitHub Secrets**. Код не скачивает изображения из новостных публикаций и не нарушает прав на их переиспользование.

### Проблемы

- `401 Unauthorized` Telegram — проверьте токен.
- `403 Forbidden` Telegram — бот не администратор канала или без права публиковать.
- Ошибка API OpenAI `401` — неверный API-ключ; `429` — тариф/лимит/баланс.
- Не приходят сообщения — см. вкладку Actions → конкретный запуск → журнал ошибок.
- `Новых материалов не найдено` — в доступных RSS за последние 24 часа нет записей, либо они уже публиковались.
- Для однократной проверки RSS без оплаты API запустите на своей машине `DRY_RUN=1 python footportal.py`.

## Технические сведения

- Только стандартная библиотека Python: не требуется `pip install`.
- Источники: Sport.ru, Sports.ru, Sky Sports, BBC Sport.
- Запоминание опубликованных ссылок ведётся в `data/posted.json`, коммитится автоматически в репозиторий после каждого запуска.
- Если часть источников временно недоступна, приложение продолжает работу с остальными.
- Если публикация уже отправлена в Telegram, ссылка фиксируется в истории, чтобы не постить её повторно.
- В Telegram отправляется заголовок, текст и кликабельная ссылка на настоящий источник.

**Примечание:** работа бота с реальными токенами и публикация в канал не были выполнены при сборке архива: для этого нужно завершить подключение ключей и прав бота.
